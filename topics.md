## Course Overview

**Credit hours:** 3  
**Prerequisites:** CPSC 27603 or equivalent

Introduction to game programming explores the design and implementation of computer-game software, including GUI/engine design, basic 2D sprite animation, dynamic object management, the component model, third-party graphics and physics APIs, and basic design of non-player entities. Relevant software-design patterns are discussed throughout.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Formulate a logical solution to a variety of problems (PO5)
- Assemble the appropriate logical structures and algorithmic steps for implementing a computer game engine (PO6)
- Write correct, clear, and concise code to solve reasonably complex problems (PO7)
- Apply concepts of program correctness, applications of programs to various subject areas, and intelligent-making and problem-solving (PO8)
- Write well-disciplined code (PO9)
- Write clean and well-documented code (PO11)
- Apply mathematical concepts that concern physics properties in a game world

## Topic Summary

### Foundations (Modules 01–04)

- **Module 01 - Introduction and C++ Foundations:** Course introduction; C++ fundamentals — classes, operators, inheritance, polymorphism; STL containers (vector, set, map)
- **Module 02 - Search, Sort, and Interactive Structure:** Search and sort algorithms; random number generation; generic interactive code structure
- **Module 03 - Object Factory and Smart Pointers:** Object factory pattern; asset library; smart pointers
- **Module 04 - Configuration:** Configuration systems

### Graphics & Architecture (Modules 05–06)

- **Module 05 - 2-D Graphics:** 2-D graphics
- **Module 06 - Components:** Component model

### Math & Physics (Modules 07–08)

- **Module 07 - Math and Newtonian Physics:** Geometry and trigonometry; linear algebra and calculus; Newtonian physics
- **Module 08 - Numerical Integration and Rigid Body Physics:** Numerical integration; Verlet integration; rigid body physics; Gauss-Seidel relaxation

### Box2D & Collision (Modules 09–10)

- **Module 09 - Box2D Introduction:** Box2D introduction; basic collision; joints and contact listeners
- **Module 10 - AABB Queries and Ray Casts:** AABB queries; Box2D debugger; ray casts

### AI & Gameplay (Modules 11–12)

- **Module 11 - State Machines and Path-Finding:** State machines; behavior trees; path-finding; A* search
- **Module 12 - Steering Behaviors:** Steering behaviors

### Polish & Advanced Topics (Modules 13–14)

- **Module 13 - Sound and Particle Generation:** Sound; particle generation
- **Module 14 - Scripting, Threading, and Networking:** Scripting; threading; networking; Theory of Fun!
